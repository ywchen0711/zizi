# 字字千金

國字、成語、注音的益智闖關遊戲，玩法仿照公視益智節目《一字千金》的各個單元。可以一個人跟電腦對手比，也可以開房間連線跟朋友對戰。

**線上玩：** https://ywchen0711.github.io/zizi/

## 模式

- **節目模式**：三關初賽（隨機抽單元）加冠軍決賽。總分前兩名進決賽，決賽比隻字片語、拆字接龍、文字五子棋或一字千金搶答，贏的人是今日冠軍。
- **單元練習**：十五個單元任選一個玩。
- **連線對戰**：建立房間會得到四個字母的代碼（也可以分享 `#代碼` 連結），朋友輸入代碼就能加入。房主可以加入電腦對手、選擇要玩節目模式或某個單元。房主離開時，房裡下一位玩家會自動接手主持。

## 時間與題數

首頁（單人）或房間（房主）的「時間與題數」可以自己指定：

- **答題秒數**：每題幾秒（3～90 秒），也是對戰單元每一回合的秒數；選「標準」就照各單元原本的秒數。
- **限時單元**：「字有發揮」和「同中求異」一共幾秒（30～300 秒）。
- **題數**：答題類單元每一關幾題。

電腦對手的難度另外選（簡單、普通、困難）。時間調短時，電腦也會答得比較快。

## 十五個單元

| 單元 | 類型 | 玩法 |
|---|---|---|
| 將錯糾錯 | 答題 | 兩個寫法（或讀音）二選一，挑出正確的 |
| 字字珠璣 | 答題 | 找一個能跟每個提示字都組成詞的關鍵字 |
| 四說新語 | 答題 | 從四句成語各取一字，組成新成語 |
| 去無成字 | 答題 | 四個部件去掉一個，照筆順組成一個字 |
| 團結一詞 | 答題 | 用上所有部件，組成兩個字的詞 |
| 聽音寫國字 | 答題 | 看注音和提示選出正確的國字 |
| 畫中有話 | 答題 | 看圖猜成語 |
| 掌握先機 | 答題 | 找出句子裡的錯別字並訂正 |
| 成語對對碰 | 答題 | 從十六個字裡找出藏著的成語 |
| 字有發揮 | 限時 | 點出所有念某個音（不分聲調）的字 |
| 同中求異 | 限時 | 打出所有符合「兩個字在固定位置」的成語 |
| 隻字片語 | 對戰 | 12×8 方格上輪流接成語，接不出來就輸 |
| 拆字接龍 | 對戰 | 每次只換一邊偏旁接成新字，左右要輪流換 |
| 文字五子棋 | 對戰 | 選對符合題目的字才能落子，先連五子贏 |
| 一字千金 | 搶答 | 看注音搶答國字，先得七分的贏 |

每個答題單元都有兩百題以上：

| 單元 | 題數 | 單元 | 題數 |
|---|---|---|---|
| 將錯糾錯 | 約 880 | 聽音寫國字／一字千金 | 約 830 |
| 字字珠璣 | 約 200 | 畫中有話 | 約 280 |
| 四說新語 | 約 430 | 掌握先機 | 約 400 |
| 去無成字 | 約 200 | 成語對對碰 | 約 1350（成語題庫） |
| 團結一詞 | 約 200 | | |

限時單元：字有發揮 52 個讀音、同中求異 34 種樣式；對戰單元用成語題庫（隻字片語）、261 個左右結構的字（拆字接龍）、24 種題目（文字五子棋）。

有一部分題目是手寫的，其餘由 `js/data2.js` 的表自動組成：同音字表（每組同一個讀音、而且只有這個讀音）換進成語裡，變成將錯糾錯、聽音寫國字、掌握先機和字有發揮；詞語表變成字字珠璣；部件表變成去無成字和團結一詞；成語題庫變成四說新語。組好的題目在 `js/pools.js` 裡逐一檢查。

答題類：越快答對分數越高。打字的地方可以用注音輸入法直接打，也可以點字卡。

## 檔案

- `js/data.js`：手寫的題目（成語約一千句、各單元題目、拆字接龍的偏旁表、五子棋題目）
- `js/data2.js`：更多成語、同音字表、詞語表、部件表、更多畫中有話和五子棋題目
- `js/pools.js`：把兩份資料組成各單元的題庫
- `js/units.js`：每個單元出題、判斷答案、對戰棋盤規則
- `js/host.js`：主持（出題、計時、計分、電腦對手）；單人時由本機主持，連線時由房主主持
- `js/net.js`：Supabase Realtime 房間（與網站存檔同一個專案）
- `js/app.js`：畫面
- `tools/test.mjs`：`node tools/test.mjs` 檢查題庫，並讓電腦把每個單元和節目模式各玩一遍

答案以教育部標準字體與《重編國語辭典修訂本》為準。
